Owned by the test lead. One line per thing a player can do. Tick it at each merge point, on
Windows and on Shahil's Mac.

|---|---|---|---|---|
| Start shift, hold the desk mic and ask a question | Your words appear, the penguin answers out loud with subtitles | | | |
| Hold Space instead of the mic | Same as above | | | |
| Type a question and press Ask | Same as above, without speaking | | | |

| Ask a 6th question | Refused: no questions left | | | |
| Stamp TURNED AWAY | A police penguin takes the traveller away; the next one steps up | | | |
| Stamp THROUGH | The traveller walks on; the next one steps up | | | |
| Finish the shift | The report shows each stamp, the truth, and the score | | | |
| Play again | A fresh shift with no leftovers from the last one | | | |
